本プライバシーポリシー（以下「本ポリシー」）は、Tsumu（以下「本アプリ」）における、 本アプリ利用者（以下「利用者」）の情報の取り扱いについて定めるものです。 本アプリは個人が個人として開発・運営しています（以下「当方」）。

1. 取得する情報

当方は、本アプリの提供に必要な範囲で次の情報を取り扱います。

1.1 端末内に保存される情報

  • 利用者が本アプリに入力した会話メッセージ、本アプリが生成した AI の応答、 及びそれらから派生する「気づき（記憶）」「知識」のデータ。これらは利用者の端末内（暗号化された SQLite データベース）にのみ保存され、当方のサーバーには保存されません。
  • 利用者が記録に任意で添付した画像。端末内の SQLite データベースに保存され、当方のサーバーには永続化されません。
  • 表示テーマやオンボーディング完了状態などのアプリ内設定。

1.2 AI 応答生成のためにサーバーへ送信される情報

利用者が本アプリで会話を行う際、応答生成のため次の情報がインターネットを通じて 当方の運用するサーバー（Cloudflare Workers 上のステートレスエンドポイント）へ送信されます。

  • 気づきを記録する（capture）操作: 利用者が入力したメッセージ本文、 直近 6 ターン分の会話履歴、および利用者が任意で添付した画像（端末内で JPEG に変換・圧縮した画像データ、最大 4 枚）。
  • 過去を振り返る（recall）操作: 利用者が入力した質問、 直近 6 ターン分の会話履歴、過去に保存された記憶要約（最大 20 件）。

当方のサーバーは受信した情報を OpenAI 社の API（GPT 系の大規模言語モデル）へ転送し、 応答を取得して利用者の端末へ返却します。サーバーは受信内容を永続化しません。

1.3 当方が取得しない情報

  • 氏名、住所、電話番号、生年月日、性別、メールアドレス等の登録情報（本アプリにアカウント機能はありません）。
  • IDFA / Advertising ID 等の広告識別子。
  • 位置情報、連絡先、マイク、カメラへのアクセス権（写真ライブラリは、利用者が記録に画像を添付する操作を行ったときに限り、利用者が選択した画像にのみアクセスします）。
  • クラッシュレポートや解析ツール（Firebase / Crashlytics / Google Analytics 等）を介した利用状況。

1.4 課金・サブスクリプションに関する情報

利用者が有料プラン「Tsumu Pro」を購入する場合、決済そのものは Apple App Store / Google Play が処理します。 当方は、購入状態（サブスクリプションの有効・無効、トライアルの利用有無）を管理するため、購入レシート、ストアが 発行する購入識別子、およびアプリが生成する匿名のアプリ内ユーザー ID（端末単位の識別子で、氏名等の本人識別情報 とは紐づきません）を、処理者である RevenueCat（§3.1 参照）へ送信します。当方および RevenueCat は、利用者の クレジットカード番号その他の決済情報を取得・保持しません。

2. 利用目的

  • 1.2 で送信された情報は、利用者へ提示する AI 応答を生成する目的にのみ利用します。
  • 当方は、機械学習モデルの学習・改善、広告配信、第三者へのプロファイル提供、その他の二次利用を一切行いません。

3. 第三者提供と外部送信

3.1 第三者処理者

当方は、AI 応答の生成に必要な範囲で、利用者から送信された情報を次の第三者処理者へ転送します。 これらは当方が委託する処理者であり、独立した提供先ではありません。

  • OpenAI, L.L.C.（所在地: アメリカ合衆国）
    • 用途: AI 応答の生成。
    • OpenAI の API 利用規約上、API 経由で送信された情報は OpenAI のモデル学習目的に利用されない ことを当方は前提としています（OpenAI Business Terms / API Data Usage Policies に基づく 既定挙動）。
  • Cloudflare, Inc.（所在地: アメリカ合衆国）
    • 用途: 当方のサーバー（Cloudflare Workers）の実行基盤。
    • Cloudflare 側で会話内容を永続化することはありません。
  • RevenueCat, Inc.（所在地: アメリカ合衆国）
    • 用途: 有料プラン（サブスクリプション）の購入状態・利用権限の管理。
    • 送信される情報は購入レシート、ストアの購入識別子、匿名のアプリ内ユーザー ID に限られ、会話内容や本人識別情報は含まれません。

上記以外の第三者（広告主、データブローカー、外部企業）に対し、利用者の情報を販売・譲渡・共有 することはありません。

3.2 外国にある第三者への提供

上記処理者はいずれもアメリカ合衆国に所在します。OpenAI 社・Cloudflare 社・RevenueCat 社は、 それぞれ同社のプライバシーポリシーに基づき、個人情報の保護に必要な措置を講じています。 詳細は各社のプライバシーポリシーをご確認ください。

4. 保管場所と保管期間

4.1 端末内データ

  • 記憶・会話履歴は利用者の端末内にのみ保存されます。
  • 利用者がアプリ内の「すべて削除」を実行するか、アプリをアンインストールすると、これらのデータは消去されます。
  • 当方が保管期間を一方的に設定することはありません。

4.2 サーバー側

  • 当方のサーバーは受信した会話内容を永続化しません（処理後直ちに破棄します）。
  • 悪用防止のため、認証トークン単位のレート制御カウンタを Cloudflare Durable Object に短期間（時間単位）保持しますが、これは会話内容を含みません。

5. 安全管理措置

  • 通信の暗号化: 端末と当方のサーバー間、当方と OpenAI 社の間の通信はいずれも HTTPS（TLS）で暗号化します。
  • 端末内データの保護: 記憶と会話履歴は端末内の SQLite データベースに保存されます。 当該データの保護は、利用者の端末の OS が提供するディスク暗号化（iOS の File Protection / Android の File-Based Encryption）に依存します。 現時点ではアプリレベルでの追加の暗号化（SQLCipher 等）は実装していません。 そのため、端末のロック画面パスコード / 生体認証を有効に設定し、最新の OS にアップデートすることを強く推奨します。
  • アクセス制御: 当方のサーバーは認証トークンを必要とし、未認証の要求は受理しません（401 を返します）。
  • サーバー側のデータ最小化: 永続化を行わない設計により、サーバー側でのデータ漏えいリスクを最小化しています。

6. 利用者の権利

利用者は次の権利を有します。

  • アクセス（開示）: アプリ内の「気づき一覧」「設定」画面から、端末内に保存されたすべてのデータを参照できます。
  • 削除: アプリ内の「設定 → すべて削除」から、端末内のすべての記憶・会話履歴を即時に削除できます。サーバーは元々データを保持していないため、削除請求はサーバーに対しては不要です。
  • 訂正: 端末内の記憶は、アプリ内の編集機能（利用可能な場合）または「すべて削除 → 再入力」によって訂正できます。
  • 異議・苦情申立て: 本ポリシーの内容、または個人情報の取り扱いに関する苦情は、本ポリシー第 8 項の問い合わせ窓口へお寄せください。
  • 監督機関への申告: 日本国内の利用者は個人情報保護委員会、EU 域内の利用者は所在地のデータ保護当局に苦情を申し立てることができます。

do-not-sell 宣言（CCPA）: 当方は、米国カリフォルニア州民の個人情報を含め、いかなる利用者の個人情報も第三者へ販売しません。

7. 本ポリシーの改訂

  • 当方は、法令変更・サービス改善等に応じ、本ポリシーを改訂することがあります。
  • 改訂時は、本ページの「改訂履歴」セクションに変更日と変更内容を記載します。
  • 重大な変更（収集情報の追加、利用目的の追加、第三者処理者の追加、安全管理措置の後退 等）が ある場合は、アプリ内またはストア掲載ページで別途案内することがあります。
